Cookie Policy

This page explains how cookie notices and browser-based site functionality are currently handled on the website.

Cookie notice

The website displays a privacy notice that explains our use of essential browser storage and lets visitors dismiss or acknowledge the notice. That preference is remembered in the browser so the notice does not repeat on every page load.

Essential functionality

The website currently uses essential browser-side functionality for page behavior, navigation state, and privacy notice preferences. Contact and registration form details are submitted to the server for processing and are not stored in browser storage by this interface.

Optional technologies

We do not currently use advertising trackers on this interface. If analytics, marketing cookies, or similar optional technologies are added later, this policy should be updated to describe what is used, why it is used, and how visitors can manage preferences.

Questions

For questions about the site experience or data handling, contact hello@harmonicshub.ng.
